A chess engine in 4 KB of Python: a 0x88 board, alpha-beta search with null-move pruning, late-move reductions, quiescence search and a transposition table, all to a fixed node budget so every trial replays identically. Built for make.fun's tiny-chess-01 bounty.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
